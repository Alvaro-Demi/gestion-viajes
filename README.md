# ✈️ Gestión Viajes

Aplicación web desarrollada con Angular y TypeScript para gestionar un registro personal de viajes.

La aplicación permite añadir, consultar, editar y eliminar viajes, almacenando la información localmente mediante `localStorage`.

## 🚀 Demo

[Ver aplicación](https://mellow-toffee-546cce.netlify.app/)

## ✨ Funcionalidades

* ➕ Añadir nuevos viajes
* 📋 Consultar la lista de viajes
* ✏️ Editar viajes existentes
* 🗑️ Eliminar viajes
* 💾 Persistencia de datos mediante `localStorage`
* 📱 Interfaz web responsive

## 🛠️ Tecnologías

* Angular
* TypeScript
* HTML
* CSS
* localStorage
* Git / GitHub

## 🎯 Objetivo

El objetivo del proyecto es desarrollar una aplicación web sencilla para practicar la creación de una aplicación CRUD con Angular, gestión de datos en el navegador y desarrollo de interfaces web.

## 💻 Instalación

Clona el repositorio:

```bash
git clone https://github.com/Alvaro-Demi/travel-manager.git
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
ng serve
```

Después abre `http://localhost:4200/` en el navegador.
